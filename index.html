견적비교 자동입력

결재상신 화면에서 수의시담 견적 데이터를 불러와 품의내용에 자동으로 채워줍니다.

v1.1

이 도구가 하는 일

MDvan(b2b.mdvan.net) 결재상신 상세 화면을 열면, 품의내용 입력창 위에 [견적비교 자동입력] 버튼이 나타납니다(수의시담 견적요청이 연결된 건에서만 표시됩니다).

  • 버튼을 누르면 해당 건의 수의시담 견적 데이터를 조회합니다.
  • 공급사명과 견적가를 낮은 가격순으로 정리합니다.
  • 품의내용의 "9. 가격조사기준" 항목 바로 아래에 자동으로 삽입합니다.
※ "9. 가격조사기준" 항목을 먼저 작성해 두어야 그 아래에 내용이 들어갑니다. 이미 "견적비교" 항목이 있으면 다시 추가할지 확인창이 뜹니다.

3사용하기

  • MDvan 결재상신 상세 화면으로 이동합니다.
  • 수의시담 견적이 연결된 건이면 품의내용 입력창 위에 [견적비교 자동입력] 버튼이 보입니다.
  • 버튼을 눌러 자동으로 채워진 내용을 확인하고, 필요하면 직접 다듬은 뒤 상신합니다.
